GIT COMMANDS I USED (with a short note on each)

pwd
  prints the folder I am working in.

git --version
  checks that Git is installed on my laptop.

echo "text" > file
  makes a file with that text inside (I used it for index.html, about.html and .gitignore).

echo "text" >> file
  adds the text as a new last line of the file, old lines stay.

ls
  lists the files in the current folder.

git init -b main
  turns the folder into a Git repository, first branch is named main.

git config user.name "name"
  tells Git which name to put on my commits.

git config user.email "email"
  tells Git which email to put on my commits.

git status
  shows what changed, what is staged and what Git is not tracking yet.

git add .
  stages every changed file so it goes into the next commit.

git add <file>
  stages only the one file I name.

git commit -m "message"
  saves the staged files as a commit with my message.

git branch feature
  creates a new branch called feature.

git branch
  lists all branches, the * is the one I am on.

git switch feature
  moves me onto the feature branch.

git switch main
  moves me back onto the main branch.

git merge --no-ff feature -m "message"
  brings the feature branch into main and always makes a merge commit, so the merge is visible in the history.

git log --oneline
  shows each commit on one short line.

git log --oneline --graph --all
  shows all branches as a small drawing, so I can see where they split and join.

mkdir temp
  makes a folder called temp (to test .gitignore).

cat index.html
  prints what is inside index.html.

git revert HEAD --no-edit
  undoes the last commit by adding a new commit that cancels it, the old commit stays in the history.

touch git_commands.txt
  creates an empty file with this name.

cat > git_commands.txt
  writes the text I paste into git_commands.txt.

git remote add origin <url>
  links my local repository to the GitHub repository.

git remote -v
  shows the GitHub links my repository is connected to.

git push -u origin main
  uploads main to GitHub and remembers it as the default branch to push to.

git push origin feature
  uploads the feature branch to GitHub.

git push
  uploads my new commits on the branch I am on.
